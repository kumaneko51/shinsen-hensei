# 信長の野望・真戦 編成支援

公開URL: https://kumaneko51.github.io/shinsen-hensei/

## 機能

- 武将・戦法検索、戦法効果のホバー表示
- 所持品チェック、自由編成／所持品編成の切替
- 最大10部隊の編成、主将・副将、突破、ドラッグ配置、枠の入替
- 共有URLの作成・読み込み、共有一覧
- プロフィール、部隊グループ、編成提案、抽選記録
- カスタム武将・カスタム戦法の端末内登録
- 端末データのJSONバックアップ書き出し・読み込み

利用者の編成・所持情報はブラウザ内だけに保存され、他の利用者からは見えません。共有URLには選択した1部隊と所持品情報が含まれます。

## クラウド機能について

元アプリのログイン、複数端末同期、全利用者共通の共有一覧・提案・抽選記録には、Supabaseなどのバックエンドが必要です。GitHub Pagesだけでは利用者ごとの認証や共通データを安全に保存できません。

クラウド機能を有効にする場合は、Supabaseプロジェクトを作成し、認証プロバイダー、データベースの行レベルセキュリティ、公開サイトURLを設定してから接続します。

## 公開マスタの登録

武将と戦法は master.json で管理します。GitHub上で master.json を開き、鉛筆アイコンから編集して Commit changes を実行すると、GitHub Pagesへ反映されます。

武将に登録できる主な項目:

- id: 重複しない半角英数字とハイフン
- name: 武将名
- faction: 勢力
- cost: コスト
- rarity: レア度
- troopType: 兵種
- command, strength, intelligence: 能力値
- skill: 固有戦法

戦法に登録できる主な項目:

- id: 重複しない半角英数字とハイフン
- name: 戦法名
- type: 種別
- rarity: レア度
- effectCategory: 効果分類
- description: 説明

JSONの記法を誤るとサイトに反映されないため、編集前の内容をコピーして保管してください。
