# 信長の野望・真戦 編成支援

公開URL: https://kumaneko51.github.io/shinsen-hensei/

## 機能

- 武将・戦法検索、戦法効果のホバー表示
- 所持品チェック、自由編成／所持品編成の切替
- 最大10部隊の編成、主将・副将、突破、ドラッグ配置、枠の入替
- 共有URLの作成・読み込み、共有一覧
- プロフィール、部隊グループ、編成提案、抽選記録
- カスタム武将・カスタム戦法の端末内登録
- 端末データのJSONバックアップ書き出し・読み込み

利用者の編成・所持情報は、ログイン前はブラウザ内だけに保存されます。ログイン後は、同じメールアドレスのユーザーだけが読める Supabase の領域へ自動保存されます。共有URLには選択した1部隊と所持品情報が含まれます。

## クラウド機能について

Supabase を接続済みです。公開サイトの「ログイン・登録」から、表示名・メールアドレス・パスワードを入力して登録できます。登録後に確認メールが届く場合は、メール内のリンクを開くとユーザー専用のクラウド保存が開始されます。

以前に同じメールアドレスで利用していてパスワードが分からない場合は、「ログイン・登録」でメールアドレスを入力し、「パスワードを再設定」を選択します。届いたメールのリンクを開くと、新しいパスワードを設定できます。

`supabase-config.js` の Publishable key は、RLS（行レベルセキュリティ）を有効にしたブラウザ公開用キーです。管理用の service_role キーやデータベースパスワードは、リポジトリへ含めていません。

パスワードは `user_profiles` や一門テーブルには保存されません。Supabase Authentication の `auth.users` 認証領域でハッシュ化して管理され、Table Editor の `public` スキーマには表示されない仕様です。`user_profiles` は本人の所持武将・戦法のクラウド保存用、`families` 以降の4テーブルは一門内共有用です。

## 一門機能

ログイン後に表示される「一門」から、一門を作成するか、招待IDで参加できます。一門へ公開した部隊は同じ一門のメンバーだけが閲覧・コメントでき、編集できるのは公開した本人だけです。

一門機能を初めて使う前に、Supabase の SQL Editor で `supabase/schema.sql` を実行してください。`families`、`family_members`、`family_lineups`、`family_lineup_comments` の各テーブルと、同じ一門のメンバーだけに限定するRLSポリシーが作成されます。

## 公開マスタの登録

武将と戦法は Supabase ではなく `master.json` で管理します。GitHub上で [master.json](https://github.com/kumaneko51/shinsen-hensei/blob/main/master.json) を開き、鉛筆アイコンから編集して「Commit changes」を実行すると、GitHub Pagesへ反映されます。

追加は、同じ種類の既存データ1件を複製して末尾へ貼り付け、`id` を重複しない連番に変更する方法が安全です。武将は `heroes`、戦法は `tactics` の配列内に追加します。各項目の最後にカンマを付ける必要があるため、編集後はJSONの形式を必ず確認してください。

武将に登録できる主な項目:

- id: 重複しない半角英数字とハイフン
- name: 武将名
- sourceName: 外部取り込み照合用の原語名
- faction: 勢力
- clan: 家名
- cost: コスト
- rarity: レア度
- stats: `leadership`、`valor`、`intelligence`、`politics`、`charisma`、`speed` の能力値
- uniqueSkill: 固有戦法
- teachableSkill: 伝授戦法
- traits: 特性一覧
- portrait: 肖像の画像URL

戦法に登録できる主な項目:

- id: 重複しない半角英数字とハイフン
- name: 戦法名
- sourceName: 外部取り込み照合用の原語名
- type: 種別
- rarity: レア度
- target: 対象
- activationRate: 発動率
- learnable: `true` は選択可能、`false` は固有戦法として選択不可
- tags: 効果分類
- summary、effect: 戦法の要約と詳細説明

JSONの記法を誤るとサイトに反映されないため、編集前の内容をコピーして保管してください。

## 一門限定の土地攻略データ（2026-09-05）

一門タブの「土地攻略データ」から所属一門の戦報・数値・解説を閲覧できます。攻略判定の絞り込みと原寸画像表示に対応しています。投稿・編集画面はありません。

勝利・引分・敗北の各戦報を保持し、結果別に絞り込めます。`attemptId` が同じ戦報は `sequence` 順に詳細画面から相互参照できます。連戦の集計は成功した同一部隊の攻略を1件とし、最初の戦闘の育成状況と開始兵数を使います。別部隊での再戦は単一部隊の平均から除外します。初攻略の平均には最初の戦闘の `firstClear: true` が必要です。画像だけで初攻略や凸数を確定できない場合は未確認として保存します。

データは Supabase の family_land_reports テーブル、画像は非公開の family-land-reports バケットで保管します。双方に一門所属を確認するRLSを適用し、クライアントには読み取りだけを許可します。画像は認証付きダウンロードを使用し、公開URL・署名付き共有URLは作りません。ログアウト・一門再読込で取得済みデータを消去し、画像の一時URLを破棄します。

追加環境では既存の schema.sql の後に supabase/land-reports.sql を適用してください。実データと画像は公開リポジトリに含めません。

### 土地レベル別の初攻略集計

土地4〜10の切替、シーズン別表示、初攻略の勝利だけを対象にした平均レベル・兵数・レベル範囲・凸分布を表示します。平均レベルは各部隊の開始時3武将平均を部隊数で平均します。不明な凸数は集計から除外します。初攻略以外・未確認・引分は「すべて」で閲覧できます。

payload の拡張項目は landLevel（数値）、firstClear（true/false/null）、season（文字列）、breakthroughs（武将順の0〜5またはnullを3件）、enemyLevel、enemyTroops です。旧データは土地5・初攻略未確認・凸未確認として扱います。画像取込・自動読取・投稿フォームは今回の閲覧画面には含みません。
