# 信長の野望・真戦 編成支援

公開URL: https://kumaneko51.github.io/shinsen-hensei/

## 機能

- 武将・戦法検索
- 所持チェック
- 最大10部隊の編成
- 大将・副将、突破、能力補正
- 端末内保存と共有URL

利用者の編成・所持情報はブラウザ内だけに保存され、他の利用者からは見えません。

## 公開マスタの登録

武将と戦法は master.json で管理します。GitHub上で master.json を開き、鉛筆アイコンから編集して Commit changes を実行すると、GitHub Pagesへ反映されます。

武将に登録できる主な項目:

- id: 重複しない半角英数字とハイフン
- name: 武将名
- faction: 勢力
- cost: コスト
- rarity: レア度
- troopType: 兵種
- command, strength, intelligence: 能力値
- skill: 固有戦法

戦法に登録できる主な項目:

- id: 重複しない半角英数字とハイフン
- name: 戦法名
- type: 種別
- rarity: レア度
- effectCategory: 効果分類
- description: 説明

JSONの記法を誤るとサイトに反映されないため、編集前の内容をコピーして保管してください。
